# visual-v2 素材目录

此目录保存林雨薇 v2 写实视觉素材：`cutouts/` 是桌面要加载的透明人物 PNG，`scenes/` 是场景背景，`masks/` 是已验收的局部换色遮罩，`recolors/` 是已验收的本地换色完整 PNG，`portraits/` 与各 `.provenance.json` 保留原始生成结果和来源记录。

目录的唯一引用来源是上层的 [`../visual-catalog.json`](../visual-catalog.json)。不要根据文件名推测可用组合，也不要直接把 `portraits/` 当作桌面资源：只有 catalog 中 `status: "approved"` 的安全相对路径会被应用加载。

## 添加或维护素材

1. 将新文件放在相应子目录，并保留来源、提示词或编辑记录。
2. 在 `visual-catalog.json` 注册完整造型或场景。人物资产必须描述真实的发型、服装、姿态、表情和色板；不能从不同照片拼出未拍摄过的组合。
3. 人物 cutout 必须是 1024×1536 的透明 PNG，IHDR color type 为 4 或 6。背景和 mask 也必须是 1024×1536 PNG。
4. 只有裙子和短裤已有被验收的局部换色范围。新增换色前，确认 mask 没有覆盖脸部、皮肤、头发或人物透明边缘，并把最终变体注册为独立 approved 文件。
5. 场景背景保持人物原图的烘焙光照不变。雨、雪和场景卡片只是环境合成；不能由此声明重新打光、真实交互阴影、全 3D 骨骼、眨眼或口型同步。
6. 私密吊带内搭包含不透明吊带、居家短裤和罩衫。它只能与 `privacy: "private"` 的场景兼容。
7. 执行 `node scripts/verify-visual-assets.mjs`，修复输出中的所有问题后再构建桌面应用。

验证脚本从 manifest 动态统计原图、换色、背景和场景，且只读取本地文件；它不会调用模型。通过文件契约检查并不代表桌面 UI 已完成生产环境交互或视觉验收。
