# 0.4.1 人物修订 · 2026-09-09

已发布 12 张人物原图的透明成品，重新派生 10 张服装配色；正式目录总数仍为 31 张。原 bob 的站立、挥手及四张配色全部改成高马尾。目录显示名称为“高马尾”，保留旧 `bob` 标识和文件路径以兼容用户已保存的选择，这些标识不再描述当前发型。

站立素材调整头身比例、腿部长度和站姿。脸以用户认可的原图为参考，恢复柔和脸型与自然轻薄刘海，避免完全露额头；樱花水手服包含站立和坐姿版本。所有角色均为虚构的 27 岁成年人。

## 生成与处理

使用内置 imagegen。每张最终原图在 `portraits/`，同名 `.provenance.json` 保存生成来源、最后编辑的提示词、SHA-256、发布目标和验收记录。提示词分两类：保持已校正身体和服装、参照原版恢复脸及轻薄刘海；原 bob 的两个造型再做仅限头发的高马尾编辑。没有使用程序拉伸人物身体。

Swift Vision 生成透明遮罩，再处理边缘、腿间背景和坐姿椅子；服装配色使用局部遮罩。10 张新配色均验证遮罩外像素不变且 alpha 一致。`comparison.png` 是部分站姿的调整前后对照，`review.png` 是应用实际场景渲染，`cutouts-review.png` 是本次 12 张成品在深浅底色上的检查图。
