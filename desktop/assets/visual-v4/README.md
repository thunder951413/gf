# 针织裙自然比例修订 · 0.4.2

用户反馈 0.4.1 针织裙比例过于细长。本次用内置 imagegen 修订长发站姿、高马尾站姿和高马尾挥手，共三张原图；依据原始面容和自然体态，收回偏小的头部、细长颈部与过度拉长的裙身体态。高马尾和轻薄刘海保留。

蓝色原图及粉色、绿色派生配色全部同步，共九张成品。六张换色均通过 alpha 一致、遮罩外像素完全不变检查。`comparison.png` 使用真实 NativeSceneCanvas，在相同布局下展示三组调整前后效果；下排为本次版本。

原图、最后提示词、来源路径、SHA-256 和验收记录在 `portraits/*.provenance.json`，透明成品在 `cutouts/`，派生配色在 `recolors/`。正式目录使用原有资产路径以保留用户选项。`visual-v3` 中这三组针织站姿和六张配色已被本轮取代；其他素材未变。
