# 按场景上传图片 · 0.5.0

桌面菜单的主入口改为“场景图片 · 上传与切换”。打开后选择书房、夏日海岸、秋日咖啡馆、冬日居所、私密卧室或春日窗边，选择一张完整图片，预览后点击“保存并应用到桌面”。每个场景独立保存图片与显示方式。

- 默认完整显示，保持图片宽高比；可改为铺满，等比裁切边缘。不会拉伸、抠图、换脸、换衣或另外叠加人物。
- 支持 PNG、JPEG、WebP，最大 12 MB，单边最大 12000 像素、总计最大 4000 万像素。PNG 的透明度保留，透明区域允许桌面点击穿透。
- 场景选择先预览，保存并应用后才切换桌面。没有图片的场景不能应用。删除当前场景的图片会停用上传模式，回到原有角色。
- 上传模式下显示用户选定的整张图片，不受旧衣柜自动换装或生活姿态切换影响。消息气泡、点击聊天、拖动和右键菜单保留。
- 图片保存在本地数据目录，不调用图片或对话模型；不写入聊天历史，也不根据图片编造现实经历、衣着或发型。此版本通过用户手动选择场景，不自动生成或随机换图。
- 首次安装上传模式尚未启用，等待用户提供图片。旧版形象保留在“原有形象（备用）”入口。

## 数据和接口

原图：`data/scene-images/<SHA256>.<ext>`；场景关联与显示方式：SQLite metadata 中的 `scene-images:v1`。原生端缓存最近使用的场景图片及确认状态，后台暂时离线或应用重启时仍可显示。

`GET /api/scene-images` 返回 enabled、activeSceneId、revision 和轻量的 scenes 列表，每项包含 id、name、imageUrl、fit。

`POST /api/scene-images` 支持 sceneId、image（data URL 或 null）、fit（contain / cover）、activeSceneId、enabled。修改图片和显示方式必须指定 sceneId。单独上传不会自动激活；原生“保存并应用”将上传与激活放在同一个请求里。

`GET /api/scene-images/files/<SHA256>.<ext>` 只返回已关联的合法文件，启用内容类型校验、nosniff 和不可变缓存。不会暴露任意本地路径。
