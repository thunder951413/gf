# 《雨夜拾光》长线情境设计

## 故事任务

- 核心问题：阮绵能否在尊重母亲遗稿的同时，让作品真正成为自己的表达，并在关系里把“需要有人并肩”说成具体请求，而不是独自扛完或替对方安排位置。
- 结尾判断：首映的意义不由规模决定，而由她在压力下作出的署名、创作和关系选择共同决定。两个结局都完成作品，但分别把亲近落在安静共享和公开并肩上。
- 外部压力：周日上午的首映时限；赞助方要求可公开展示的九十秒样片、明确的遗稿说明和可靠的放映方案；旧影院线路不稳定。
- 阮绵的旧策略：一紧张就把感受翻译成任务清单，靠多做、抢先决定和轻巧玩笑维持“我能处理”的形象。
- 具体需要：希望自己的新增创作被看见，也希望有人在她忙乱时指出真正有效的那一帧；她能自己负责决定和后果，不把陪伴写成拯救。
- 现实检验：设备故障迫使她舍弃准备充分的大方案，用前两章实际收集的声音、路线和手工灯片完成首映。

## 三章因果

1. **第一章｜雨夜来信**：保留原七个节点和所有既有事实、选择 ID。原结局节点改成章末转轴，由公开提交或内部试映分别进入次日准备。
2. **第二章｜白昼排练**：两条旧分支各自兑现后汇合。街区采样改变成片素材；剪辑分歧让阮绵必须说清她怕什么、要什么；赞助电话给出公开时限和技术条件。关系从解谜默契变为能承受不同意见的合作。
3. **第三章｜把光交给人群**：疲惫中的宵夜提供短缓冲；首映前线路故障回收钥匙、车票路线或茶铺路径的实际用途。阮绵亲自砍掉复杂方案并完成放映，最后由用户选择首映后的相处方式，抵达两个独立结局。

## 主要线索与回收

- 母亲遗稿：谜底 → 署名与改编难题 → 阮绵在首映中明确哪些画面属于母亲、哪些声音与路径属于自己。
- 城市路线：茶铺消防梯或车站镜面路线 → 白昼重新采样 → 首映故障时成为安全布线与引导观众的依据。
- “顾问/唯一观众”邀请：章末玩笑 → 准备期里具体合作与分歧 → 最终成为可选择的约会或公开搭档关系，不预设用户承诺。
- 铜钥匙：开启秘密 → 作为工作台压住线路图 → 首映后留在两人之间的空座上；偶然只开启问题，临场故障靠前文准备和人物决定解决。

## 两个结局

- **雨停以后**：首映完成后，两人留下看空墙上的余光。阮绵提出一顿不谈项目的早餐，把亲近落在生活时间里。
- **灯亮在人群中**：阮绵带用户回到仍在交流的街坊中，公开感谢其所选的实际贡献，并约下一次共同采集，关系落在可继续兑现的并肩行动上。

两个结局都不以“拯救她”或放弃事业换取亲近；差异是私密余韵与公共协作的情感动态及后续安排。
