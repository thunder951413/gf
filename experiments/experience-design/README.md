# 生活与分享解耦原型

这是用于推演落地机制的内存原型，没有接入正式服务。

运行：`node --test experiments/experience-design/cycle.test.mjs`。5项测试通过。

核心推演：第1天开始阅读，第3天进入中段，第7天读完。即使一次消息也没发送，生活也按时间推进。第1天发出的消息如果第9天才被回复，仍然取回第1天的内容细节，而不是用第9天的读完状态替代它。期间的未回复只影响是否再次主动联系，不影响阅读进展。

来源、事件与日期由测试样例明确给出。它不负责自然语言理解、不包含真实模型对话、不实现SQLite事务/跨进程并发，也不证明内容有趣或回复自然。正式集成应复用现有消息队列、版本检查和原子提交，再进行真实模型多轮验收。
