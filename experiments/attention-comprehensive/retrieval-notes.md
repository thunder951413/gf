# Automatic attention retrieval experiment

`retrieval.mjs` is a bounded offline simulator. It imports the existing event-time-capped `salience` function and adds deterministic lexical retrieval, user-turn observation, conservative exposure accounting, short-lived negative gates, recent-focus pronoun fallback, duplicate filtering, and proactive novelty sampling.

It uses BM25-style term weighting over `Intl.Segmenter` word tokens plus CJK character bigrams. That makes the experiment inspectable and dependency-free, but lexical overlap cannot establish meaning, truth, entailment, identity, or contradiction. Long phrases require broader CJK overlap so a single shared fragment does not count as relevant. This can still miss synonyms and match ambiguous homonyms.

Substantive raw user turns are retained as dated `type: "user"` records with `recordKind: "user_utterance"`. Questions are marked `asserted: false`; no facts are extracted from them. A current utterance is excluded from its own retrieval. Refusals create expiring proactive-initiation gates (three days; thirty for cancellation/correction language), rather than permanently deleting a topic. Explicit user recall can still retrieve the raw cancellation/correction evidence. Positive and negative clauses separated by ordinary punctuation are ranked independently; complex clause scope remains a known failure mode.

`observeAssistant` records an exposure only when the delivered assistant text conservatively overlaps a selected detail. Its return value and later diagnostics report uncertain selections that were not counted. It does not extract assistant self-experience: lexical rules cannot reliably distinguish autobiographical claims, unverified fiction, and real sourced events. Callers may add separately verified `life` or `source` memories.

Proactive selection does not inherit the last user query's lexical score. It discounts prior exposures and applies seeded jitter only within 88% of the top score. The seed makes identical runs reproducible; call order remains part of the experiment state. Selection returns whole records only, so clipped fragments do not consume or bypass the character budget. At most two complementary non-duplicate records from one topic are allowed. `snapshot(day).memories` includes future records with zero salience so baseline and retrieval arms can share the same raw inventory; `futureCount` identifies them.
